# memory/

Dated notes, one file per day: `YYYY-MM-DD.md`. Day-level detail goes here;
what lasts is promoted to `../MEMORY.md`. Nova searches these notes for each
message and shows what it recalled in the margin of the conversation.

People, groups and enduring topics get a short file each, in `people/`,
`groups/` and `topics/`: a `# Full Name` heading, an `Also called:` line for
nicknames, then what matters. A group's file names its members. The Stellar
Map (Nova theme) draws these as planets and constellations, and every memory
that names one as a moon in its orbit. Edit or delete a file and the map
follows.
