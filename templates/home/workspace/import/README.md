# workspace/import/

Put things here that you want Nova to learn about you from: notes, a profile
you wrote, an export from another assistant, or a memory export from another
Nova (the memory.json in a memory-… folder in that Nova's exports/ folder).

Then tell Nova in chat. It reads a file and suggests memories, or loads a Nova
memory export once you say yes. Either way they arrive in Memory unreviewed,
for you to confirm, correct or forget.
