## Context
ADR-025 pinned CI to Node 22 LTS. M0 relies on Node's built-in `node:sqlite` (ADR-084) and on
running TypeScript through Node's type stripping (ADR-085); both need Node 24 or later.

## Decision
CI and the E2E container use Node 24 LTS. Development may use newer Node releases. `engines.node`
is `>=24`.

## Consequences
No native SQLite module to compile per platform. Node 22 is no longer supported.
