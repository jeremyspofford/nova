# M1 — Demo

## Preconditions
- `npm ci && npm run build`; a fresh data directory. No network is needed: the Hub creates a
  "Mock (offline)" provider on first start.

## Script
1. `NOVA_DATA_DIR=$(mktemp -d) node apps/hub/src/main.ts` and open the printed setup link;
   choose **Finish setup**.
2. Onboarding: the provider step lists **Mock (offline)**; Continue through model, display name
   (enter one) and tools; on the last step choose **Finish without the sample** (or **Run this**
   to summarize the bundled sample document).
3. **New chat** (Ctrl/Cmd+N, Alt+N in a browser tab), type `Hello`, press Enter: the reply streams.
4. Send a long message; press **Stop** (or Esc) mid-reply: the partial reply stays, marked
   "Stopped".
5. Stop the Hub (Ctrl+C), start it again with the same data directory, reload: the chat and the
   stopped reply are still there. Open **Search**, type `Hello`: the chat is found with the match
   highlighted.
6. Ctrl/Cmd+K → "Toggle light and dark theme": colors change. Settings → Appearance and
   Settings → Keyboard: change the accent, rebind a shortcut.
7. Optional: Settings → Accounts → add an OpenAI-compatible or Ollama provider and chat with a
   real model.

## Expected results
- Streaming, stop with partial retention, persistence across a restart and search all work
  offline.
- No serious or critical accessibility violations on the chat and settings screens.
- The Hub starts in under 3 s.
