# M2 — Demo

Ask with Anthropic, switch to a local model, see memory retained (`docs/17` M2).

## Preconditions
- `npm ci && npm run build`; a fresh data directory.
- An Anthropic API key and a local model server (Ollama at `127.0.0.1:11434` with a model
  pulled). Without them, the J2 journey below runs the same script against local fake servers.
- Optional: a second machine with a model server, for a compute node.

## Script
1. `NOVA_DATA_DIR=$(mktemp -d) node apps/hub/src/main.ts`, open the setup link, **Finish setup**,
   then **Skip setup**.
2. Settings → Accounts → **Add a provider** → Anthropic, paste the key, **Save and test**. Then
   Settings → Models → **Detect** finds the Ollama server; **Connect** adds it.
3. New chat, pick the Anthropic model, ask a question. Switch the model picker to the local
   model and ask a follow-up: the answer uses the earlier turns. Each reply shows the model that
   answered.
4. Move the composer's **Faster ○──●──○ Smarter** control to Smarter and send: the chat records
   the preset, the reply the model it resolved to. **Advanced…** opens Settings → Models, where
   the presets' models, reasoning levels, speed and fallbacks can be edited and saved.
5. Send "I prefer window seats." Settings → Memory lists "The user prefers window seats.";
   **Correct** it to aisle seats. A new chat's model is given the corrected fact; a **New
   temporary chat** (clock button next to New chat) is given none, is marked, and is deleted
   when you leave it.
6. While a long reply streams, send another message: it is queued ("Queued: 1") and runs next
   (Settings → General switches to Steer). **Edit** a sent message: a second version appears
   with "‹ 2 / 2 ›" and the first is kept. **Branch from here** starts a new chat that carries the
   conversation; Inspector → Branches shows the tree and compares two branches side by side;
   Inspector → Side chat asks a question without adding to the chat. Ctrl/Cmd+F (Alt+F in a
   browser tab) finds text in the chat; Search ranks matches across chats.
7. Projects → **New project** with instructions and a pasted or uploaded text source: chats in
   the project follow the instructions and cite the source.
8. Optional compute node: Settings → Devices → **Add compute node** shows a command; on the
   other machine run it (`nova-compute enroll --hub <url> --token <token> --backend
   http://127.0.0.1:11434`, then `nova-compute run`). The node and its models appear; a chat on a
   node model runs there (the turn records `node:<id>`). **Revoke** cuts it off.

## Expected results
- One conversation works across two providers with its context; presets resolve to real models.
- Memory is extracted, editable, used in later chats and kept out of temporary chats.
- Search returns ranked results with snippets and jumps to the message.
- No serious or critical accessibility violations on the chat, Models and Memory screens.
