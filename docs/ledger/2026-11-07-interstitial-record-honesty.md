**2026-11-07 · Interstitial Research · The skill's run record now says what really happened**
- What changed: four fixes from the Part 3 report (PR #364). (1) Privacy class: a topic about the person ("my", "our"…) is personal-derived, and so is a search that carries a distinctive word from MEMORY.md; before, only recalled notes counted, so the P1 run was recorded "public" while its queries came from the person's health record. The outbound check is told before it decides; the person's words never go into the record. (2) Honesty: the record gains `unbacked`, the things the answer claims that the run doesn't back (interstitial or adjacent findings with no checked claim, gaps "confirmed" with no search sent, "verified" with no passing claim, "searched" with no search sent; negated mentions don't count). When there are any, a note under the answer says so, and the Activity line adds "the answer claims more than the run backs". (3) Cost: the tokens each call spends carrying the skill's playbook count as the skill's, so a run whose searches were all core no longer reports 0% overhead (Part 3's G1 was +698% against plain Nova and recorded 0). (4) Withholds say why: an untrusted check now tells the model that no search from the skill can leave, not to retry, and to say no outside search was done, instead of claiming the query "could carry something of the person's own"; each held-back search records `why_withheld` (untrusted or judged).
- What you can now do: nothing new while the switch stays off. With it on, a run's record and the note under the answer can be taken at their word.
- Still unfinished: the skill stays off (Part 3: both templates fail their eval). The word test for MEMORY.md is a heuristic: a common word that happens to be in the person's memory makes a search personal-derived (the safe direction).
- Checked: five new tests in tests/ingest/interstitial.test.js (topic and memory-word privacy, end to end with MEMORY.md; the untrusted-check message and `why_withheld`; unbacked headings and words, with negation; playbook cost share). Lint, typecheck and npm test ran in iso.sh.
