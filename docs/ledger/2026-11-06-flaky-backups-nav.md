**2026-11-06 · Tests · The Backups slow-read test can no longer hang the UI gate**
- What changed: the UI test "Backups Try again during a slow read still asks again" (added in #336) hung main's UI gate for its full 15 minutes. It held the next Backups read and waited, with no limit, for that read to arrive. But saving the backup settings a moment earlier fires profile changes of its own, and each one starts a Backups read. If that read was still on its way when the test's own profile change arrived, the page joined it instead of asking again (by design), so no new read ever came and the test waited forever. The test now first lets those earlier reads finish: it makes one more profile change and waits until the page has handled it and its read is done. The stream delivers changes in order, so every earlier one has been handled too. Only then does it set up the hold. Its wait for the held read is now a Playwright wait, so if the read ever fails to come, it fails after 30 seconds with a clear message instead of hanging. The app itself did not change.
- What you can now do: nothing new in Nova. Main's UI gate stops hanging on this test.
