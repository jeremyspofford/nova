**2026-11-08 · UI rebuild · The side rail takes the approved design, with search and the version stamp**
- What changed: beside the rail (tablet, a foldable opened, desktop) the rail is rebuilt to the approved composition: flat rows on the rail's own ground instead of glass, the current place a tinted row in the primary text, a hairline over the foot, every row at least 44 px. Where a desktop has room for it without taking width from reading (a new derived band in layout.css, --band-rail: the open rail, the centre's content width and a full right column; never below the three-column band plus the open rail's extra width), the rail opens to 256 px: each row an icon, the place's name and a quiet count (tasks that need you, things waiting in Activity, Health's problems: counts the app already had, now handed to the rail), under an uppercase "Places" label. A first cut opened it from the three-column band plus its extra width alone; at 1024 px that left a conversation's prose at 42ch (M9 asks 45–75), so the band was raised. Narrower (tablet, a foldable opened, a 1024 px desktop), it stays at layout/rail-width with each icon over its name, since those are touch screens with no hover to name an icon-only row. A search button under the orb opens the existing command palette (the same openPalette, not a second palette). The rail's foot shows the running build from GET /api/v1/version: the version and the short commit, amber with a dot when a redeploy is pending, and a "v" when the rail is slim. It is plain text, not a link: Nova has no About page yet. The places themselves are unchanged (orb for Home, Chat, Tasks, Memory, Automations, More, Settings), so every view stays reachable in every layout. Phones and a foldable's cover screen are exactly as they were. The service worker cache moves to v42.
- What you can now do: tap the search button to search and jump anywhere without a keyboard; see at a glance how many tasks need you; see which build Nova is running.
- Still unfinished: the composition's workspace switcher (Nova has nothing to switch between), its spaces (Nova has none), the recent-conversations list in the rail (the conversations drawer is its own piece of the rebuild), and a phone's bottom tabs versus a drawer (an open owner decision) are not built.
