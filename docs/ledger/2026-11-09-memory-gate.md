- What changed: the memory-gate template (#277) now has a live consumer behind a flag that ships off (`features.memory_gate`, or `NOVA_FEATURE_MEMORY_GATE=1`). The template, its questions, cases, bounds, results and model digest are unchanged.
  - The runner's `keep()` is asynchronous and awaited. In a conversation that read nothing from outside, each `<remember>` asks memory-gate with the person's exact message, Nova's visible reply as context only, the candidate and up to five nearest existing memories.
  - Outcomes: skip writes nothing; merge keeps the existing memory; flag holds it for the person as a candidate with a reason; save writes it as today, unreviewed.
  - Nova relies on an outcome only from a model that passed the template's eval, or from its own deterministic check (an exact duplicate, an empty candidate). Every other case writes as today: no gate, no template, an untrusted answer, or no answer.
  - A conversation that read outside content keeps today's path: everything waits for the person, and the gate is never asked.
