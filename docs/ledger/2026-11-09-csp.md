**2026-11-09 · Security · A strict Content-Security-Policy on every HTML page**
- What changed: Nova sent no CSP. The owner approved adding one on 2026-11-08, and src/core/csp.ts now applies it to all 22 HTML routes.
  - Directives: `default-src 'self'; script-src 'self'` plus two hashes; `style-src 'self'` plus a per-response nonce; `style-src-attr 'unsafe-inline'`; `img-src 'self' data:`; connect, font, manifest and worker all `'self'`; `object-src 'none'; base-uri 'none'; form-action 'self'; frame-ancestors 'none'`.
  - The two inline index.html scripts (the iOS status-bar snippet and the never-blank timer) are allowed by sha256 hashes the server computes from the shipped file. They stay inline so the never-blank timer still works offline.
  - The runtime design-system `<style id="ds">` changes at runtime, so it carries a fresh nonce per response. WebKit refuses a refilled nonced style, so theme.js re-creates the element with the same nonce.
  - The styleguide's inline onsubmit became a listener.
  - HTML responses also get `X-Content-Type-Options: nosniff` (dev mode lacked it) and `Referrer-Policy: same-origin`. no-referrer would make the app's own POSTs send `Origin: null`, which the API refuses.
  - The supervisor's safe-mode page gets its own `default-src 'none'` policy, with its one inline style hashed.
  - No external host and no blob: are needed; the mesh URL is only displayed.
  - Test-harness changes the CSP forced (none weakens an app assertion):
    - axe is injected through page.evaluate instead of addScriptTag
    - test-added styles carry the nonce; they had been refused silently
    - the fold CORS check also accepts a connect-src refusal
    - the WebKit screenshot's own style is ignored only while a screenshot is taken
    - one themes.test.js source-text assertion follows theme.js
- What you can now do: rely on the browser refusing any script or style block that isn't Nova's own, even if text ever reached a page unescaped.
- Still unfinished: one owner call.
  - `style-src-attr 'unsafe-inline'` remains. The templates write per-render values into style="" attributes (skeleton boxes, fit bars, table alignment, wait countdown, topology, the ring, the styleguide), and removing it showed about 24,000 violations. It covers attributes only: no selectors, and loads stay held to img-src and font-src.
  - Removing it means moving those values to element.style and changing STYLE_ATTRIBUTES in csp.ts.
