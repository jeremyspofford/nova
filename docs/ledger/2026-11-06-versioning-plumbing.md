**2026-11-06 · Versioning · Nova has a version, knows which build it runs, and every change now comes with a changelog entry**
- What changed: Nova's version is now 0.1.0-alpha.1, set in one place (package.json). The running Nova knows its commit and when it was built (or, when that wasn't recorded, when it started, and says which), and whether it is the latest merged build. It learns the latest merged build only from a small file the merge step writes, never from GitHub. Its API answers this at /api/v1/version, and Nova says it in chat from its own state: "Running <commit>, latest merged <commit> — redeploy pending." when it is behind. A CHANGELOG.md now exists at the top of the repository, in plain language, with one opening entry summing up the alpha so far; it is generated from one small file per change, so changes don't collide on it. CI now refuses a change to what Nova ships that leaves out its changelog entry or its ledger entry, unless it is labelled no-changelog.
- What you can now do: ask Nova which version and build it is running and whether a redeploy is pending; read what changed in CHANGELOG.md.
- Still unfinished: the About area, the footer stamp, the in-app changelog and the pipeline dashboard are the UI track's, waiting on your reaction to their designs; they will read what this change provides. The merge queue starts writing the deploy record, bumping the version and tagging main from now on. Until the preview is redeployed with the record in place, Nova says it doesn't know the latest merged build.
- Checked: unit tests for the build identity (from the environment, from git, unknown), built versus started, behind, the same and not known with their words, every malformed deploy record refused, the deploy-record script (mode 600, atomic, bad input refused), the API route and its guard, Nova's own briefing; the changelog generator (deterministic, SemVer order, fragment shape, release) and a drift test that CHANGELOG.md matches its fragments; the CI rule against real diffs in a scratch repository; the full gate.
