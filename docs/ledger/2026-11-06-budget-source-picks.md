**2026-11-06 · Models screen · Every pick says whether it assumed the Mac's measured GPU limit or the estimate**
- What changed: each recommendation on the Models screen (the pick for a task, its smaller alternative, and the tight option shown when nothing fits comfortably) now carries where the budget behind its verdict came from: the GPU memory limit set on the Mac, or Nova's estimate of the macOS default. It is taken from the same verdict that ranked the model, so it can't disagree with it. On a Mac, the "Recommended for this device" section says it once, in exactly the budget line's words: "GPU memory limit set on this Mac: 56.0 GB." or "Estimated GPU share of 16.0 GB unified memory: 10.7 GB (macOS default)." When a plan is on screen, the Memory budget section above already says that same sentence about that same budget, so the picks don't repeat it; with nothing planned there is no budget line, and the picks say it. Off a Mac nothing new is shown: a graphics card's budget is always its own memory and the processor's always half the RAM, and their lines already say so. If the picks on one screen ever disagreed (they can't today: they are all worked out for the same device), each would say its own.
- What you can now do: on a Mac with nothing planned yet, you can see whether the recommendations assumed the limit you set or Nova's guess, before you plan one.
- Still unfinished: the estimate fractions for a Mac without a limit set are still unchecked on a real Mac (see the Mac GPU limit entry).
- Checked: a unit test checks that on a Mac with a 56 GB limit set the chat pick and its alternative say "measured", and on the same Mac without one they say "estimate"; and that a tight-only option says "measured" with a 24 GB limit set and "estimate" on a 35 GB Mac at the 2/3 estimate. The browser copy of the engine is regenerated and its drift test passes. A UI test checks, in the app, that the picks don't repeat the budget line while a plan shows it, and that with the plan emptied the picks say "GPU memory limit set on this Mac: 56.0 GB."
