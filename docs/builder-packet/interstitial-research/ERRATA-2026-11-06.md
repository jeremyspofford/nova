# Interstitial packet — errata, 2026-11-06

Source: Codex reconciliation of its continuous-learning draft against
the packet (2026-11-06), verified by Muse against the packet texts
the same day. Applies to `interstitial-research/SKILL.md` and
`VERIFICATION-AND-IMPROVEMENT.md`. Two flags stand, one does not.

## E1 — Field-map authoring (flag STANDS)

SKILL.md §2 step 3 and §4 describe the field map as "generated
through the Decision Service template registry," with
`interstitial.field-map` returning a typed list output. The Jev /
Decision Service record is clear that the service returns calibrated
probabilities only — it cannot author lists or text.

Resolution (already the builder's Part 1 adaptation #2, logged for
its PR): the chat model authors the field map; code validates it
against the strict §4 schema and records it; only judgement calls go
through Decision Service templates (`interstitial.verify-transfer`,
`interstitial.outbound-check`). The §4 field-map entry stands as the
SCHEMA and caching contract (cache-miss only; keys include template
version + model version + privacy class; personal-derived/sensitive
maps are per-task cache only), not as a Decision Service generation
claim. Where SKILL.md says otherwise, this errata governs.

## E2 — Verify-transfer threshold boundary (flag STANDS)

SKILL.md §4: a transfer is used only if battery answers (a), (b),
(c) each return ≥0.7; "any answer in 0.4–0.7 quarantines." Exactly
0.7 falls in both bands as written.

Resolution: the quarantine band is **0.4 ≤ p < 0.7**. A return of
exactly 0.7 PASSES. Below 0.4 discards, as written. Same reading
applies to VERIFICATION-AND-IMPROVEMENT.md §D's "(0.4–0.7)".

## E3 — Cost-cap breach cadence (flag DOES NOT STAND)

Codex reported SKILL.md §3 as saying two breaches feed the
improvement loop, against three elsewhere. Checked by Muse
2026-11-06: §3 states no breach count. SKILL.md §8 and
VERIFICATION-AND-IMPROVEMENT.md §G both say **3 runs at the same
depth exceeding that depth's cost cap** (alongside every 10 logged
runs, or 2 owner corrections). The texts agree. No change.
