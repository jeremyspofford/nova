# UI reference set (owner-approved 2026-11-06)

Binding visual references for the UI rebuild. Compositions are
diffed against these pictures, not against descriptions.

- `linear-my-issues.avif` — Linear. STEAL FOR: app shell + Tasks.
  Density without clutter, one accent colour, hairlines over boxes,
  strict row grid.
- `things-3-ipad.jpg` — Things 3. STEAL FOR: Home / morning board /
  personal lists. Calm, whitespace, typography as hierarchy.
- `claude-ai-chat.jpg` — Claude.ai. STEAL FOR: Chat. Content-width
  column, almost no chrome, composer as the single focus, orb as
  Nova's one standout.
- `obsidian-graph.webp` — Obsidian graph view. STEAL FOR: graph /
  topology surfaces incl. the future immersive mode. Restraint —
  nodes glow because nothing else does.
- Arc (no local file; the host refused the download) — STEAL FOR:
  context switching (devices / homes / work contexts as spaces).
  Reference: https://techword.nl/reviews/1796110/review-arc-browser/
  (spaces overview screenshot).
- Raycast (text reference) — STEAL FOR: command palette + Settings
  clarity. Search-first, keyboard-first, zero decoration.

Recommended blend (owner, via Muse): Linear's structure, Things'
calm, Claude's chat, Arc's context-switching, the orb as the only
standout element.
