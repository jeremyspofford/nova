### Security
- What Nova remembers now reaches its model marked as your memory: MEMORY.md, your recent notes and the notes a message recalls each come in a block that says where it came from, and nothing written in a memory can end that block early or pass itself off as an instruction.
- A memory you made from something Nova captured (your screen or a recording) is checked again before Nova uses it. If the check blocks it, Nova leaves it out and the conversation records that it did; otherwise it is shown to the model as words that came from outside, not as your own.
