### Added
- An About page, under Settings and from the version stamp. It shows which version is running,
  whether a newer merged build is waiting ("redeploy pending"), and when this one started, with
  links to what's new and to the pipeline.
- A "What's new" page that shows Nova's changelog in the app, newest first. It's the same text as
  the changelog file, read from it directly.
- A pipeline page showing what has shipped, what's in progress and what's planned, for each area
  of work. It's built from Nova's own records each time you open it.
- The version stamp is now a link to About. On a phone it sits at the foot of the navigation drawer.
