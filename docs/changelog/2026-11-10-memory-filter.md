### Added
- Memory has a filter box. Type a word and the list narrows straight away to what Nova keeps about
  it, in memories and day notes, with a count like "3 of 12 shown." What you type stays in the page:
  it isn't sent anywhere, put in the address or saved. Items waiting for your OK always stay in view.
### Fixed
- A memory Nova can't trace to a conversation no longer says "from a conversation". It says "Nova
  cannot show where this came from yet." That covers memories made from captured items or sent by a
  device.
