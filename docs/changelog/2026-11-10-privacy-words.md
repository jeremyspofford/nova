### Changed
- Where you choose your privacy mode (in setup, Settings › Privacy and Settings › Models), Nova now
  says where chat goes and what each chat turn carries before you send anything. Local first is a
  rule for Nova's own model work; a chat program that counts as the cloud is asked on every turn,
  with your standing files and memory, recent day notes, the conversation and any file Nova reads.
- The Providers page's chat line says what each turn carries when chat goes to the cloud.

### Security
- Local only now means no cloud model, with no exception. If you had turned on screening by Jev,
  it is suspended while Local only is on: nothing goes to Jev, and Settings › Models says so. It
  applies again if you choose Local first.
