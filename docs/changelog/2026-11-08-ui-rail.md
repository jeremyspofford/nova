### Changed
- The side rail takes the approved design: flat rows on the rail's own ground, a hairline over the
  foot. On a wide desktop it opens out: each place is an icon, its name and a quiet count (tasks that
  need you, things waiting, problems) on one row under a "Places" label. Narrower, it stays slim.
- A search button at the top of the rail opens the command palette, so it works by touch too.
- The rail's foot shows which build Nova is running: the version and the short commit (a "v" when
  the rail is slim), amber when a redeploy is pending.
