### Changed
- Setup's privacy question now offers three answers to pick from: Local-only (recommended), Local
  first and Cloud allowed. If a typed answer could mean either, Nova asks again and sets nothing.

### Fixed
- When your privacy setting stops the first chat, Nova now tells you the next step inside Nova and
  gives you a button for it: choose a local chat model that is already on, point chat at the model
  your devices run, or set one up in Settings › Models. It no longer only names settings in a file.
- Setup and the "Bring in your notes" card name the real folder for imports, inside Nova's own folder
  on the computer Nova runs on, instead of a `~/workspace/import/` that read as your home folder.
- Giving the local model address (NOVA_OLLAMA_URL) as a name such as `ollama` or `gpu-box.local` no
  longer stops Nova with a programmer's error. You get one plain line saying which setting it is and
  the forms it takes, and a name saved in your settings leaves the local decision model off with the
  reason instead.
