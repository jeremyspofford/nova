### Added
- The styleguide has a status icon for Nova's states: idle, listening, thinking, working,
  speaking, needs-you, success, paused, stopped and offline. Each state is one glowing ribbon with
  its own shape, and the icon morphs smoothly from one state to the next. Its preview shows every
  state at three sizes, with buttons to change state and a reduced-motion switch. The app itself
  doesn't use the icon yet.
- The styleguide's intro now names Nebula as Nova's lead design.
