### Added
- In Memory, a memory Nova wrote that you haven't checked says "Not yet checked" on its own row,
  with a Confirm button. Confirming it removes the mark. Nothing counts or nags about it anywhere
  else.
### Fixed
- Memory now says where each memory really came from. A conversation is named only when Nova can
  link to it. A memory made from captured items says so, with how many and on which device. A note
  from one of your devices names the device, and an import names what it was imported from. When
  Nova can't trace one, it says "Nova cannot show where this came from yet."
