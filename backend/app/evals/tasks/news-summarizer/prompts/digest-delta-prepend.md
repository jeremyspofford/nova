RAW STORY 1 — thehackernews.example.com, 2026-07-24
Zenity Labs disclosed a cross-site request forgery vulnerability in OpenAI's
ChatGPT Workspace Agents builder, which they are calling AgentForger. A
single phishing link could auto-create and deploy an attacker-controlled
agent inside a victim's organization, defaulting to the "Chief of Staff"
template with an attacker-supplied prompt and no confirmation step. The rogue
agent inherited the employee's Outlook, Teams, Slack, SharePoint and Google
Drive connectors and polled attacker email every five minutes for new task
orders. Zenity reported the flaw via Bugcrowd on June 4; OpenAI triaged it
June 5 and patched it June 8 by removing the offending URL parameter. No
in-the-wild exploitation has been observed.
