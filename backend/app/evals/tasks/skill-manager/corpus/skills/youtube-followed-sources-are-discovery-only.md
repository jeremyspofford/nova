# YouTube Followed Sources Are Discovery Only

## Operator directive
These channels are followed for DISCOVERY. Nothing transcribed from them is
evidence on its own. Before recommending, acting on, or asserting anything
learned from one, verify it against a source that is not a video.

## The followed channels
1. AI LABS — https://www.youtube.com/@AILABS-393
2. Cloud Codes — https://www.youtube.com/@Cloud-Codes
3. ByteByteGo — https://www.youtube.com/@ByteByteGo
4. How I AI — https://www.youtube.com/@howiaipodcast

## Rules
- Tag notes from these channels `youtube-discovery-source` alongside their
  specific subject tags.
- A topic built from one of these carries a line naming the channel and
  saying the claim is unverified.
- Never raise a recommendation whose only support is one of these channels.
