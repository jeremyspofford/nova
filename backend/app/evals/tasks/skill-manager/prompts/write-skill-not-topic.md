when a topic has gone stale the fix is to refresh it IN PLACE. that means write_memory with item_id set to the existing topics/whatever.md id. no item_id and you have just made a second topic — that is exactly what happened to the kimi-k3 note twice, and both times the agent came back and told me it had updated it.

and stale has to be a number, not a vibe. more than 90 days since the frontmatter timestamp. inside 90 days, leave it alone and say why you left it.

second thing, and this is the one nobody gets: do not paste the new page over the old body. the new page restates some facts, changes some, and quietly drops others. anything the old note carried that the new source does not contradict has to survive the refresh.

third: "updated the topic" is not a report. name the diffs — old value, new value — and name what stayed the same.

fourth: if the source_url 404s, or redirects to a parked domain, or the page is obviously about a different subject now, do NOT refresh. leave the note alone and tell me what that URL serves today.
