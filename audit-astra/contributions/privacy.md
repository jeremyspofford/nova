# Privacy, security, and model-routing audit contribution

Baseline: merged source `d948aa0a442a9f930b86f4516eeea21981b76714`, isolated worktree `/workspace/nova-audit-astra`, 2026-11-09. All findings below apply to **merged source and disposable instances of that source**, not to the owner's deployed preview, which this agent did not reach. No product files changed. No real model, account, external integration, credential or real backup was used. The restricted whole-system threat model was deliberately not ingested; this is not a whole-system security certification.

## Assessment

The consequential confirmed defect is a privacy change race: an inference already waiting on a local model can still fall back to the cloud after the person selects local-only. The local-only control passes. Nova also intentionally has a separately disclosed screening opt-in that weakens local-only; this is a product-policy conflict, not a hidden fallback. Preserve the existing exact-model evaluation gate, plain refusal messages, capture holding area, broker isolation, and genuine device-access boundaries while closing the gaps.

## Maintenance observations that matter to reliability

- **Policy is applied independently at several boundaries.** Runner rechecks every step and DecisionService every send, while Models snapshots once and Receipts selectively rechecks. NOVA-001 is a concrete consequence, not merely an architectural taste. Prefer one enforceable send-time contract plus specialized adapters.
- **Two credential architectures coexist.** Broker-local value isolation and legacy Core value handling demand different claims, redaction and migration rules. The cost is visible in the constructor's direct value callbacks and incomplete whole-product gate; preserve the broker's small fixed surface during migration.
- **File-shaped context loses structured provenance.** The capture intake gate, memory records, standing-file rendering and day-note recall become separate policies. This contributes to NOVA-005 and the data-integrity agent's deletion findings. Define one structured context contract and render files only as a projection; keep SQLite as current source of graph/memory identity.
